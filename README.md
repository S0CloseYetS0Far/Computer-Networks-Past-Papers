# Computer Networks Past Papers

Interactive practice for **CS330 Computer Networks**: 362 solved past exam questions, sorted by lecture chapter.

**Use it online: https://s0closeyets0far.github.io/Computer-Networks-Past-Papers/**

- Questions come from past midterms, finals and quizzes, including the latest midterm (2026, Term 2).
- Each question is solved from the lecture slides and shows the slide number where the answer is.
- Chapters: 1 Introduction · 2 Application Layer · 3 Transport Layer. Network- and link-layer questions from older finals are not included.
- One question per page with Show solution, Prev / Next, Shuffle, and a "Review my mistakes" step when you finish.

## Run it locally

Open [`site/index.html`](site/index.html) in any browser. No install needed.
